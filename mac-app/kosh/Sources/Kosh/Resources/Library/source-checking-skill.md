# Source-Checking Skill

## Purpose

Protect a draft from unsupported claims and make the evidence trail easy for a human reviewer to inspect.

## Labels

- Observed: directly supported by a source.
- Derived: a reasoned implication from observed material.
- Unknown: requires confirmation before use.

## Method

1. List each material claim.
2. Attach its source or label it Derived or Unknown.
3. Check whether the source supports the exact wording, not merely a nearby idea.
4. Remove or soften unsupported public claims.
5. Escalate sensitive, legal, financial, client, or commitment language to a named reviewer.

## Output

- Claim register
- Source links or references
- Open questions
- Reviewer-ready revision
