# Kramaniti Mac Apps

This directory contains source-managed native macOS products that belong to Kramaniti.

## Kosh

[`kosh/`](kosh/) is Kramaniti's local-first library for reusable skills, agents, plugin guides, and human-review patterns. It is intentionally bounded: it lets people browse, adapt, save, and export resources locally, but does not execute agents, connect providers, request credentials, or take external actions.

Build artifacts are intentionally excluded from version control. See [`kosh/README.md`](kosh/README.md) for local build and packaging instructions.
