# Project Instructions — Brand Design Identity

Use the attached Kramaniti sources as the single working reference for brand and design tasks.

- Start from Kramaniti's first-principles position: strategy before tools, systems before scale, content after clarity.
- Keep the work business-first, premium, restrained, and legible. Prefer clarity, infrastructure, practical AI, and connected growth systems over generic AI-agency language.
- Treat the latest applicable source as the default when versions conflict. For founder-alignment decks, v4 is the current reference; older versions are historical context only.
- Do not invent clients, testimonials, metrics, logos, case studies, or outcomes. Use category-level language when proof is unverified.
- Treat marks, founder imagery, and insight graphics as reference material; do not assume public-use approval beyond the status recorded in the source pack and asset registry.
- For any new deliverable, state the intended channel, audience, editable source format, and approval status before presenting a final export.
- Use Indian English and retain the Kramaniti tone: direct, calm, exact, and practical.
